Runner

Each website gets a small control panel. A shared counter in state.json decides whose turn it is: 0 = idle, 1…N = step to run. This page only starts and resets it.

1 · Folder

Choose the folder with functions.json and urls.json (Chrome or Edge). It also holds state.json, panels/ and logs/.

2 · Execution plan

3 · Control panels

Generate the scripts, then for each site: open it, press F12 → Console, paste its script, and click “Select folder” in the panel that appears (pick the same folder). Allow popups for each site.
